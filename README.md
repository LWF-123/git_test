# 门诊挂号系统｜Java控制台课程设计项目
> 基于Java实现的控制台门诊挂号管理系统，采用内存存储，未接入数据库。
> 实现三种角色权限：管理员、医生、患者，共8项核心业务功能。

## ✨ 功能列表
1. **登录与角色识别（管理员 / 医生 / 患者）**
   账号密码登录，自动识别角色，进入对应操作菜单。
2. **科室与医生信息管理**
    - 科室：新增、修改、查询、启用/停用科室
    - 医生：新增、修改、查询、修改在职状态
3. **排班（号源）管理**
   新增排班、修改排班信息、修改号源容量（加号）、指定星期停诊、查询排班
4. **患者挂号**
   流程：选科室 → 选择医生 → 选择就诊日期 → 选择号别（急诊/专家/普通）→ 自动生成排队号
5. **我的挂号查询 & 退号**
   查看个人全部挂号记录；仅待就诊记录支持退号操作，退号后状态变更为已取消
6. **医生叫号模块**
   查看候诊队列、呼叫下一位患者、标记患者过号、标记接诊完成
7. **优先级排队策略**
   急诊 > 专家 > 普通；同号别按照排队号先后顺序排队
8. **号源与挂号量统计报表（管理员）**
   按日期统计挂号总量与各类型挂号数量；挂号状态分布统计；号源使用率计算

## 🚀 项目运行说明
1. 开发环境：IDEA + JDK17+（使用switch模式匹配语法）
2. 导入项目到IDEA
3. 直接运行 `Main.java` 的main主方法
4. 在控制台输入账号密码登录系统

> ⚠️ 重要说明：项目使用内存模拟存储，程序关闭之后所有数据会丢失；数据库相关逻辑预留注释，后续可扩展MySQL。

## 👥 角色权限
| 角色 | 权限 |
| ---- | ---- |
| 管理员 | 科室管理、医生管理、排班维护、查看挂号统计报表 |
