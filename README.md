# 门诊挂号系统（Java控制台版）
> Java 控制台项目，纯骨架实现，**8大核心业务模块**，支持管理员、医生、患者三种角色登录。
> 项目用途：课程设计 / 实训项目，暂未接入数据库，全部数据内存模拟。

## ✅ 功能清单
1. **登录与角色识别**：管理员 / 医生 / 患者，登录后进入对应菜单
2. **科室与医生信息管理**
    - 新增、修改、查看科室，启用/停用科室
    - 新增、修改医生，查看医生列表，修改医生在职状态
3. **排班（号源）管理**
    - 新增排班、修改排班信息
    - 修改号源容量（加号）
    - 设置停诊（指定星期休息）
    - 查询全部排班、按医生ID查询排班
4. **患者挂号流程**
   > 选科室 → 选医生 → 选择就诊日期 → 选择号别（急诊 / 专家 / 普通）→ 自动生成排队号
5. **我的挂号 & 退号**
    - 查询本人所有挂号记录
    - 对【待就诊】的挂号执行退号操作
6. **医生叫号功能**
    - 查看候诊队列（自动按优先级排序）
    - 叫下一位患者
    - 标记患者过号
    - 标记接诊完成
7. **优先级排队规则**
   > 急诊 > 专家 > 普通；同号别，按排队先后顺序
8. **号源与挂号量统计报表（管理员）**
    - 按日期统计挂号总量、急诊/专家/普通分别数量
    - 挂号全状态分布统计（待就诊 / 叫号中 / 已就诊 / 已取消 / 过号 / 已过期）
    - 号源使用率计算

## 🚀 运行方式
1. 使用 IDEA 导入项目
2. 确认JDK版本 >= 17（使用了switch模式匹配）
3. 直接运行 `Main` 类main方法
4. 输入账号密码登录（内存模拟用户，可在UserService中新增测试账号）

## 🧑‍💻 角色说明
- **管理员**：科室管理、医生管理、排班维护、查看统计报表
- **医生**：查看候诊队列、叫号、标记过号、完成接诊
- **患者**：挂号、查询我的挂号记录、退号

## 📌 项目说明
1. 数据全部保存在内存，**重启程序数据全部丢失**，属于项目骨架，未接入MySQL数据库
2. 所有数据库相关代码使用注释预留，后续可直接对接MyBatis/JDBC
3. Git分支管理：
    - `dev`：开发分支（当前开发所有功能）
    - `main`：主分支，用于存放稳定版本
